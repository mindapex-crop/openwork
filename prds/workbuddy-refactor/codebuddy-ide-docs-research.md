## 1. 简介

页面：`/docs/ide/Introduction`

### 功能点清单

- **产品定位**：腾讯云推出的 AI 辅助编程工具，通过 AI 深度融入全流程，实现从产品构思到产品发布的一站式高效交付；支持 **IDE、插件、CLI** 三种形态，覆盖专业开发者到零基础用户。
- **全流程 AI 驱动开发**：
  - 智能需求分析：自然语言描述产品构思 → AI 自动生成结构化需求文档（PRD）
  - 设计稿智能生成：支持自然语言、手绘草图转高保真设计稿
  - 设计稿一键转代码：内置 Figma 功能，设计稿转化为可维护的前后端代码
  - 智能编程助手：实时代码续写、多文件代码生成、行间对话解决问题
- **多形态产品矩阵**：
  - CodeBuddy IDE：产品/设计师/全栈开发/编程初学者；产设研一体工作台，支持可视化调试，主打"对话即编程"
  - CodeBuddy 插件：日常编码开发者；即插即用、融入现有工作流（VS Code / JetBrains / 微信开发者工具 / Xcode / Visual Studio）
  - CodeBuddy Code（CLI）：DevOps/运维/SRE/资深开发者；命令行工具，支持 Shell/文件/网络操作，任务编排能力强
- **内置生态服务集成**：BaaS 服务集成（Supabase、腾讯 CloudBase，自动处理数据库、用户认证）；一键部署（CloudStudio、EdgeOne Pages 等）；组件库支持（TDesign、MUI、Shadcn 等）；多模型支持（混元、DeepSeek 等）
- **语言与框架支持**（理论不限制）：前端 HTML/JavaScript/CSS/Vue/React/Bootstrap；后端 Node.js/Python/Java/C#/Ruby/PHP；客户端 Java/Kotlin/Swift/Objective-C/C#；其他 C++/Go/Rust/TypeScript/Shell/PowerShell/R/MATLAB
- **四阶段核心能力**：
  - 产品阶段：智能需求分析（自然语言→PRD）、需求优化建议
  - 设计阶段：自然语言生成交互原型、手绘草图转高保真设计稿、组件库快速拼装、AI 视觉优化（自然语言指令实时调整设计风格）
  - 研发阶段：设计稿一键转代码（内置 Figma，打通设计到研发"最后一公里"）、智能补全和错误修复、单元测试自动生成、代码理解与审查（快速解释既有代码、智能代码审查、工程结构分析，支持 `@workspace` 和 `#Codebase`）
  - 部署阶段：快速部署（一键部署至沙箱环境）、分享协作（生成可公开访问链接）
- **插件版本要求**：VS Code 1.82；IntelliJ IDEA/PyCharm/GoLand/CLion/PhpStorm 2022.2；Android Studio Flamingo；微信开发者工具 1.06.2409140；Xcode 14.0；Visual Studio 17.0；插件市场搜索"腾讯云代码助手"
- **CLI**：Node.js 18.0+，`npm install -g @tencent-ai/codebuddy-code`

### UI 界面设计细节

- 文档站为 VitePress 风格：顶部"快速导航"锚点 TOC、页脚"上一页/下一页"分页器、"最后更新"时间戳
- 大量使用表格呈现版本/环境对比；TIP/WARNING 提示块；带语言标注的代码块（bash/json/markdown/mermaid）

### 核心流程

- **需求→设计→研发→部署**闭环：想法→PRD 需求→原型/高保真设计稿→前后端可维护代码→沙箱一键部署→公开链接分享

## 2. 安装和登录

页面：`/docs/ide/Getting-Started/Installation`

### 功能点清单

- **环境要求**：macOS 11 (Big Sur) 及以上；Windows 10 及以上（不支持 Windows 7/8/8.1）；不满足则无法启动
- **下载**：访问 CodeBuddy CN 官网（copilot.tencent.com/ide/），按处理器选择对应版本
- **安装**：macOS 安装包拖拽到 Applications；Windows 双击安装包 → 弹窗选"确定"（仅当前用户安装）→ 勾选"我同意此协议" → 选择安装位置 → 一直"下一步"
- **登录（三种账号体系）**：
  - 个人版：点击"登录" → 跳转登录页（个人微信或手机号登录）→ 返回 IDE
  - SaaS 企业版（旗舰版）：点击"登录"拉起浏览器验证窗口 → 选"企业·腾讯统一身份" → 手机验证码 / 邮箱 / SSO（输入企业域名）登录；仅开通企微认证源则直接企业微信扫码；多认证源则腾讯统一身份 SSO 用户名密码
  - 专有云企业版（专享版）：联系企业管理员获取；拉起浏览器登录页输入账号密码
- **更新**：点击右上角"账户" → "检查更新" → 左下方新版本推送 → "立即安装"按钮
- **设置**：设置页左侧导航菜单分为**通用、对话、Tab、文档**四个分区

### UI 界面设计细节

- 欢迎界面含"登录"按钮；登录走系统浏览器验证窗口，成功自动回跳 IDE
- 右上角"账户"头像入口（下拉含检查更新）；新版本推送出现在窗口**左下方**（卡片 + 立即安装按钮）
- 设置页为左侧分区导航（通用/对话/Tab/文档）+ 右侧配置区

### 核心流程

- 下载 → 安装 → 登录（个人/企业）→ 检查更新 → 设置

## 4. 用户指南·概述

页面：`/docs/ide/User-guide/Overview`

### 功能点清单

- **基础能力**：智能对话（多轮对话与复杂逻辑推导）；代码补全（毫秒级预测，深度适配项目私有风格）；Figma 转代码（一键转可维护前端代码）；组件库集成（预置企业级 UI 组件，自然语言调整样式布局）；智能诊断（自动发现 Bug 与性能瓶颈，一键修复）
- **代码补全 Pro（NES）**：Next Edit Suggestions 前瞻式编辑，"写一补十"；不仅补全当前行，还预测下一步编码意图，自动对关联后续代码块（下一行逻辑、函数体结尾）给建议；默认开启，手动触发 `Ctrl + Shift + Enter`
- **快捷唤起**：macOS `⌘+I` 内联对话、`Ctrl+⌘+I` 侧边栏对话；Windows `Ctrl+I`、`Ctrl+Win+I`
- **基础交互**：新建会话（顶部 `+` 图标）；上下文引用（输入框输入 `@`）；多模态输入（粘贴截图、导入 Figma 链接）
- **三大模式**：
  - Ask（对话模式）：技术问答与概念解释，不直接修改代码
  - Craft（Agent 模式）：当前上下文代码生成与局部修改，响应迅速
  - Plan（计划模式）：最强自动化，AI 先制定任务清单经确认后自主执行读取、修改及环境检查
- **自定义 Agent**：点击"+ 创建 Agent"定制专属智能体
- **进阶特性**：Memory（记忆偏好，自动记录偏好与项目背景）；Rules（`.codebuddy/rules` 强制遵循架构/编码规范）；Skills（`.codebuddy/skills/` 专业指令集，如安全审计、性能压测）；MCP（接入数据库、实时搜索等第三方工具）；自定义模型（API 接入）；自定义指令（斜杠指令个性化适配）
- **集成与生态**：云服务集成（CloudBase、Supabase、CloudStudio，数据库管理与一键预览部署）；前端组件集成（标准化组件库规范生成符合企业设计系统的代码）；设计组件集成（`Add from Figma` 按钮从内置 Figma 导入设计稿转生产代码）

### UI 界面设计细节

- 侧边栏对话（聊天面板）与内联对话（编辑区输入框）两种形态并存
- 模式可随时切换（文档建议大范围改动用 Plan 模式）；快捷键按 macOS/Windows 分列

### 核心流程

- 新建会话 → 输入需求（@ 引用/粘贴截图/导入 Figma）→ 选模式（Ask/Craft/Plan）→ 执行 → 预览/部署

## 5. 智能体模式·概述

页面：`/docs/ide/User-guide/Agent-Mode/Overview`

### 功能点清单

- **智能体模式（Agents）**：面向复杂任务协作，在 IDE 内创建任务、持续对话、查看执行结果，同一界面完成文件检查、代码审查和结果预览
- **适合场景**：分步骤推进的开发任务；边聊边改、持续追问的任务；需要查看产物/文件/变更/预览结果的任务；同时处理多个任务
- **建议阅读顺序**：快速开始 → 创建任务 → 任务管理 → 任务对话 → 结果查看

### UI 界面设计细节

- 智能体模式为 IDE 内独立"工作台"界面（与侧边栏对话布局不同）

## 6. 智能体模式·快速开始

页面：`/docs/ide/User-guide/Agent-Mode/Quickstart`

### 功能点清单

- **CodeBuddy Agents 定义**：IDE 中 Agents 模式，需求拆分为多任务并行推进，同一界面查看产物、全部文件、代码变更和预览结果
- **核心优势**：多任务并行；更适合审查（产物/全部文件/变更视图）；结果预览更直接（前端和应用类任务结合预览视图边看边调）
- **适用场景**：
  - 编程模式：代码生成/审查/Bug 修复/重构、项目理解、网站/应用开发
  - 工作模式（默认）：文档生成（README/API 文档/技术设计文档）、数据分析（上传数据文件分析可视化）、PPT/报告生成、深度研究、邮件编辑、周报生成
- **环境要求**：已安装并打开 IDE；已打开项目；网络连接；已注册登录账号
- **进入方式**：右上角"打开 Agents"入口；或 IDE 首页工作模式卡片底部"开始工作"按钮；未登录显示登录引导页
- **发起第一个任务**：输入需求（如"帮我在当前项目中添加一个用户登录功能"）→ 选运行模式和 AI 模型 → 发送（或回车）→ 智能体自动使用当前项目与分支作为工作上下文 → 可多任务并行，侧边栏随时切换

### UI 界面设计细节

- **三大区域布局**：
  - 侧边栏：任务列表（按文件夹分组）、搜索与管理、底部用户头像
  - 对话区：任务标题栏、消息列表、输入框
  - 上下文区：右侧面板（产物/全部文件/变更/预览），通过任务标题栏切换按钮展开/收起
- 新建任务页含欢迎语、输入框、任务入口；默认"工作模式"可切换"编程模式"；IDE 首页有工作模式卡片

## 7. 智能体模式·创建任务

页面：`/docs/ide/User-guide/Agent-Mode/Create-Task`

### 功能点清单

- **工作模式选择**：工作模式（文档/报告/调研/数据分析，默认选中）；编程模式（代码开发场景）；模式差异（任务类型、工作目录：编程模式需指定本地项目目录、工作模式直接开始）；**系统记忆上次选择并自动回填**
- **填写任务**：左侧"新建任务"→ 选模式 → 输入框描述需求 → 调整运行方式和模型 → 发送（或回车）
- **选择工作目录**（编程模式）：输入框右下角"选择文件夹"
- **添加上下文**：`@` 引用文件/文档/规则；`Ctrl/Cmd+V` 粘贴截图；上传按钮或拖拽文件；补充说明（目标/范围/约束/结果标准）
- **任务开始后**：新任务出现在左侧任务列表；对话区持续展示执行过程与输出；右侧上下文区展示产物/全部文件/变更/预览；可补充消息或并行创建任务

### UI 界面设计细节

- 新建任务页：模式选择器（默认工作模式）、输入框、运行方式与模型选择器（输入框下方）、右下角"选择文件夹"
- 输入框支持拖拽、粘贴图片、上传按钮

## 8. 智能体模式·任务管理

页面：`/docs/ide/User-guide/Agent-Mode/Task-Management`

### 功能点清单

- **任务列表**：左侧边栏，两类信息——"最近任务"（最近访问/更新）与"按工作空间整理的任务"；任务卡片显示标题、当前状态、最近更新时间或创建时间
- **搜索与筛选**：顶部搜索框（按标题）+ 筛选按钮（筛选面板）：按状态、按日期、重置
- **任务状态（六种）**：进行中 / 已完成 / 失败 / 待处理 / 规划中（分析需求整理执行思路）/ 已归档
- **管理操作**：点击卡片进入任务页；搜索/筛选定位；已有任务继续发消息；清理不再需要的任务
- **继续处理**：已完成/失败/中断任务可重新进入补充消息（细化结果、失败补充信息重试、基于结果扩展新需求）

### UI 界面设计细节

- 任务卡片化（标题+状态标签+时间）；顶部工具栏搜索框 + 筛选按钮（面板支持状态/日期/重置）

## 9. 智能体模式·任务对话

页面：`/docs/ide/User-guide/Agent-Mode/Conversation`

### 功能点清单

- **对话方式**：与 IDE 侧边栏交互习惯一致（输入需求、补充上下文、查看执行过程、继续追问）
- **顶部操作**：打开编辑器（快速打开任务关联编辑器/项目）；保留工作空间（同一项目持续追问，减少重复切换）
- **消息发送**：新需求、修改意见、继续追问
- **文件和图片上传**：`Ctrl/Cmd+V` 粘贴截图；上传按钮或拖拽文件
- **执行过程展示**：回复内容、执行中阶段说明、结果摘要、可展开查看的中间步骤
- **中断与继续**：执行中输入框区域显示**停止入口**，可随时中断；中断后可补充说明、调整需求重发、基于已有内容继续

### UI 界面设计细节

- 对话区顶部：任务标题 + 操作按钮；输入框底部上传入口；执行中显示停止按钮；消息流中插入阶段说明/结果摘要/可展开步骤卡片

## 10. 智能体模式·结果查看

页面：`/docs/ide/User-guide/Agent-Mode/Results`

### 功能点清单

- **右侧结果区四类内容**：
  - 产物：生成文件与交付物；左列表右预览；支持**表格预览**（表头/数据完整性/排版）与**文档预览**（版式/标题/正文）

  - 变更：本次任务代码修改；文件列表、每个文件改动情况、选中文件后的具体 diff

### UI 界面设计细节

- 结果区为同一右侧面板，四视图切换对照；产物区"左列表右预览"分栏；表格/文档内嵌渲染；网页预览带地址栏+刷新按钮

## 11. 内联对话

页面：`/docs/ide/User-guide/inline-chat`

### 功能点清单

- **功能特性**：原地编辑——代码编辑区直接对话；**默认开启**
- **唤起方式**：菜单（圈选代码块 → 弹出菜单单击 **Edit**）；快捷键（Windows `Ctrl+I`、Mac `Command+I`）；`Escape` 退出/关闭
- **使用流程**：唤起输入框 → 输入自然语言需求 → AI 编辑所选代码或生成新代码 → 单个或批量接受/拒绝
- **典型场景**：快速生成代码模板（函数/类/配置）；代码重构优化（重构/重命名/逻辑优化）；代码诊断修复（类型校验、安全检测）；需求快速落地
- **FAQ**：无法唤起（检查快捷键冲突、重启 IDE）；代码不符预期（详细描述、多次尝试）；撤销用 `Ctrl+Z`/`Command+Z`

### UI 界面设计细节

- 输入框嵌入代码编辑区（光标位置）；圈选代码弹出菜单含 Edit 按钮；生成结果支持单个/批量接受、拒绝

## 12. 代码补全

页面：`/docs/ide/User-guide/Code-Completion`

### 功能点清单

- **代码补全**：基于当前代码与项目上下文的多行内联补全；支持 Python、JavaScript、TypeScript、Java、C/C++、Go、Ruby 等
- **触发**：自动触发（开始新行、缩进后输入、输入括号/分隔符、光标移到行尾）；手动 `Option+\`（macOS）/ `Alt+\`（Win/Linux）
- **接受**：全部 `Tab`；逐行 `Cmd+Down`/`Ctrl+Down`；逐词 `Cmd+Right`/`Ctrl+Right`；取消 `Escape`
- **NES**：分析最近编辑模式 → 预测下一步 → 显示跨多行/影响代码不同部分的建议；手动触发 `Ctrl+Shift+Enter`；`Tab` 接受、`Escape` 取消；默认启用；命令面板"CodeBuddy: Quick Settings"切换或设置 `codingcopilot.enableNextEditSuggestions`
- **配置**：
  - 全局开关：`codingcopilot.enableAutoCompletions` 或 Quick Settings "Auto Completions"
  - 语言级开关：`codingcopilot.enableCompletionLanguage`（示例 python/javascript true、markdown/plaintext false）
  - 生成偏好：`codingcopilot.generationPreference` —— 智能模式（多行）/ 单行模式

## 25. Plan 模式

页面：`/docs/ide/Features/Plan-Mode`

### 功能点清单

- **定位**：让「计划」成为研发流中的第一公民；在 IDE 内完成需求澄清、方案设计、任务拆解与执行协同；把 MCP、Skill、Subagent 编织成可插拔矩阵
- **传统 AI 助手困境**：AI 收到指令立即动手，缺少"规划"环节，导致数据结构与现有系统不匹配、用了不熟悉的库、命名风格不一致、扩展能力未按预期使用、漏功能
- **Plan Mode 解法**：需求澄清对齐预期；方案预览执行前可审阅；完整规划避免反复；计划持久化状态可追溯
- **Plan vs Craft 对比**：Plan=先规划后执行（复杂功能/架构设计/多文件协同，输出完整方案，可控性高，智能编排扩展）；Craft=直接执行（局部修改/单文件优化/Bug 修复，直接代码结果，边执行边调整）
- **Plan 典型场景**：新功能从零实现；多文件协同修改；UI/UX 设计与实现；存量项目改造；复杂任务拆解
- **核心价值**：规划准确性（渐进式澄清对话）；方案全面性（需求分析+技术架构+视觉设计+任务拆解）；执行可控性（生成代码前审阅调整）；扩展协同性（智能编排 MCP/Skill/SubAgent）；知识复用性（完成的 Plan 保存为 Markdown，作为项目知识库）
- **进入方式**：打开侧栏选 Plan Mode；查看已保存计划列表或新建计划；未完成计划保留上下文与执行进度
- **五步生命周期**：
  1. **需求澄清（Prepare）**：描述需求/粘贴需求文档 → AI 提出 1-2 个关键问题（技术栈、功能范围、限制条件，可提供选项供选择）→ 回答后 AI 生成需求总结，确认进入下一步；支持粘贴需求文档或设计稿截图
  2. **方案制定（Prepare）**：AI 先给实施大纲，再在项目中搜索相关代码/设计/文档生成方案草稿；方案包含：需求分析、技术方案（选型/架构/关键组件/数据流）、视觉设计（UI 风格/交互逻辑/配色）、任务列表（步骤清单+依赖关系+优先级）、扩展能力（推荐 MCP/Skill/SubAgent 及用途）；只使用已配置扩展，避免幻觉调用
  3. **方案编辑/确认（Ready）**：可编辑正文内容、技术方案、任务列表（插入/删除/重排）、扩展能力（增删插件或智能体）；确认前检查：技术方案是否符合现有架构、任务拆解完整性/依赖顺序、设计规范一致性、扩展能力合理性
  4. **方案实施（Building）**：点击"开始执行"→ 状态变 Building，任务按序执行；AI 每完成一个任务标记状态实时反馈；执行中可随时暂停、提出新需求或调整方向；深度调用 MCP/Skill 扩展；执行中调整：微调方案（diff 高亮显示变化）、切换 Craft 快速修复局部问题、中断恢复（遇到新需求 AI 暂停当前计划处理后再恢复）
  5. **方案完成（Finished）**：查看生成的代码和修改文件；计划自动保存为 Markdown（`.codebuddy/plans/`）；可下载计划文件导出分享；历史计划可作为上下文引用复用
- **使用原则**：单一 Plan 聚焦单一功能模块（过大 Plan 导致命名不一致/接口风格混乱）；功能模块完成后再开始下一个；复杂需求由 AI 自行拆分
- **Preview 审阅价值**：技术方案/任务拆解/设计规范在执行前审阅，修正成本几乎为零（vs 代码完成后重构）
- **扩展能力协同**：Skills（注入领域知识，如 frontend-design）；MCP（连接外部服务，如 Context7 获取框架最新 API 文档）；SubAgents（处理特定子任务，如 debug-with-logger）；Integration（打通部署和数据库，如 CloudBase/CloudStudio 一键部署）
- **复用价值**：上下文传递、Token 节省、知识沉淀；建议在新对话引用历史 Plan、把成功架构保存为模板
- **经验法则**：架构级改动用 Plan，细节级调整用 Craft

### UI 界面设计细节

- 侧栏入口：选择 Plan Mode → 可查看已保存计划列表或新建计划

- 完成状态支持下载计划文件

## 26. Subagents

页面：`/docs/ide/Features/Subagents`

### 功能点清单

- **Subagents 定义**：专门的 AI 助手，通过自定义 System Prompt、Tools 和 MCP 服务等处理特定类型任务（代码审查、调试、数据分析）
- **优势**：专业化分工更精准高效；灵活权限控制（仅授予必要 Tools）；跨项目复用（user 级别全局生效）；可团队共享
- **两种模式**（设置页中在 Subagents 名称后展示）：
  - **agentic**：由主 Agent（Craft Agent）自动判断调用时机；拥有独立上下文窗口，执行时不污染主会话；**调用后不能中途干预**（只能等任务完成返回结果，或手动中断对话）
  - **manual**：用户手动选择并完全替代主 Agent，适用于深度定制交互流程；创建后在 Agent 选择框中选中使用
- **作用范围**：project 级别（`.codebuddy/agents/`，仅当前工作区生效）；user 级别（`~/.codebuddy/agents/`，全部项目生效）
- **创建**：本地存储为 Markdown 文件；推荐在设置页 Agent Tab 下 Create Agent 按钮创建；选 User Agent Tab 创建 user 级别，否则 project 级别
- **配置字段**（agentic/manual 差异）：Name（唯一标识，均必填）；Description（用途描述，agentic 必填/manual 可选）；Auto Run（调用工具是否需要用户同意）；System Prompt；Model；Tools Built-In（内置工具列表）；Tools MCP（MCP Server）
- **示例**：agentic 型 timezone-introducer（frontmatter 含 name/description（含触发示例）/model/tools/agentMode/enabled/enabledAutoRun + System Prompt）；manual 型 weather-expert（agentMode: manual）
- **Tips**：单一明确职责；Description 从专长/范围/触发条件三方面写（bad: "A helpful assistant for code." / good: "Expert code review specialist..."）；System Prompt 明确定义角色职责、操作流程、约束边界；Tools 仅添加所需（提高安全性并聚焦）

### UI 界面设计细节

- 设置页 Agent Tab 下 Create Agent 按钮；Subagents 名称后展示模式标签（agentic/manual）
- Agent 选择框可选中 manual 模式 Subagents
- agentic 与 manual 两种模式有不同配置表单（agentic 含 Description/Auto Run 等，manual 精简）

## 27. Skills 技能库

页面：`/docs/ide/Features/Skills`

### 功能点清单

- **Skills 定义**：模块化、自包含的能力包，通过专门知识、工作流和工具扩展 AI Agent 能力（类似"入职指南"，把通用 Agent 变为专业专家）
- **能提供**：专业工作流（自动多步骤程序）；工具集成（处理特定文件格式/API 的指令）；领域专业知识（公司知识/架构/业务逻辑）；打包资源（脚本/参考资料/资产）
- **Skill 结构**：建立在 `.codebuddy/skills/` 下：
  - `SKILL.md`（必需）：YAML frontmatter（name、description 必需；allowed-tools 可选；disable 可选）+ Markdown 指令
  - `scripts/`：可执行代码（Python/Bash 等），用于需确定性可靠性或重复重写的任务
  - `references/`：按需加载到上下文的文档（数据库架构/API 文档/领域知识/公司政策），保持 SKILL.md 精简
  - `assets/`：用于输出中的文件（品牌资产、PPT 模板、HTML/React 样板代码）
- **渐进式披露三级加载**：元数据（始终在上下文，~100 词）；Skill 主体（触发时加载，<5k 词）；打包资源（按需加载，无限制）
- **创建流程**：理解需求 → 规划资源 → 在 `.codebuddy/skills/` 创建目录 → 编写 SKILL.md（YAML + 指令性语言 "To accomplish X, do Y" + 引用资源）
- **最佳实践**：description 具体明确说明何时使用；SKILL.md 用动词开头的指令；长文档放 references；信息不重复
- **管理**：设置页可视化界面；集中管理 Project Skills 和 User Skills；右上角"导入 Skill"按钮导入从网络获取的 Skills

### UI 界面设计细节

- 设置页 Skills 管理界面：项目级/用户级分组列表 + 导入按钮（右上角）

## 28. Hook 功能

页面：`/docs/ide/Features/Hooks`

### 功能点清单

- **Hook 定义**：在 AI Agent 执行的关键节点插入自定义脚本，精细控制 Agent 行为；**完全兼容 Claude Code Hooks 规范**
- **功能特性**：7 种关键事件支持；工具拦截（执行前后验证/修改/阻止）；上下文注入（会话不同阶段动态注入）；并行执行（多 Hook 自动并行）；自动去重（相同命令去重）；灵活配置（正则匹配、超时控制、项目级/用户级）；会话跟踪（避免重复触发 SessionStart）；安全可靠（错误处理和超时机制）
- **7 种事件**：
  1. **SessionStart（会话启动）**：每新会话触发一次（对比 conversationId）；用途：初始化项目环境、注入项目上下文、设置会话级配置、加载规范文档；matcher 字段 source（startup）
  2. **SessionEnd（会话结束）**：清理临时资源、保存会话状态、生成会话报告；matcher 字段 reason（other）
  3. **PreToolUse（工具执行前）**：验证工具参数、修改工具输入、阻止危险操作、权限检查、审计日志；matcher 匹配 tool_name（Bash/Write/Read，支持正则 `Write|Edit`、`*` 全匹配）；输出可 allow / 修改参数（modifiedInput）/ deny / ask（请求用户确认）
  4. **PostToolUse（工具执行后）**：记录日志、后处理输出、触发后续操作、发送通知；输入含 tool_response
  5. **UserPromptSubmit（用户输入提交）**：预处理输入、添加上下文、检测关键词、输入验证；全部提交触发；可阻止（stopReason）
  6. **Stop（Agent 停止响应）**：提供反馈给 Agent（exit code 2 时 stderr 注入下一条消息）、记录状态、触发后续任务
  7. **PreCompact（上下文压缩前）**：保存重要信息、提供压缩指导、备份上下文；matcher 字段 trigger（manual `/summarize` / auto）
- **脚本规范**：stdin 收 JSON（通用字段 session_id、transcript_path、cwd、hook_event_name + 事件特定字段）；stdout 返 JSON（continue、suppressOutput、systemMessage、stopReason、hookSpecificOutput）
- **退出码**：0=成功允许继续；1=非阻塞错误（stderr 警告）；2=阻塞错误（PreToolUse 阻止工具、Stop 提供反馈、PreCompact stdout 作压缩指导）
- **环境变量**：`CLAUDE_PROJECT_DIR`（兼容）、`CODEBUDDY_PROJECT_DIR`（CodeBuddy 特定）
- **配置位置**：项目级 `<workspace>/.codebuddy/settings.json` 覆盖用户级 `~/.codebuddy/settings.json`；字段：matcher（空串或 `*` 全匹配、`Bash`、`Write|Edit`、正则）、command（推荐绝对路径、支持环境变量、可含解释器、需执行权限）、timeout（秒，默认 60，简单验证 5-10s / 文件操作 15-30s / 网络 30-60s）
- **完整示例**：命令安全验证（阻止 rm -rf / 等危险命令）；智能修改命令参数（npm install 自动加 --legacy-peer-deps）；文件修改前自动备份（Write/Edit 前备份到 .codebuddy/backups）；会话启动注入项目上下文；上下文压缩前保存重要信息
- **最佳实践**：脚本开发（幂等、健壮）；安全性（输入验证、命令注入防护、路径遍历防护、权限最小化）；性能优化（减少执行时间、优化 matcher、并行注意）；调试技巧
- **FAQ**：Hook 未执行（检查配置路径/权限）；执行超时（调 timeout）；调试（查看日志）；多个 Hook 顺序（并行）；参数修改不生效；SessionStart 每次请求触发（检查 conversationId 对比）

### UI 界面设计细节

- 无独立 UI 界面（配置文件驱动）；设置页可能存在 Hook 相关配置入口；运行时通过弹窗/系统消息展示 permissionDecision ask 的用户确认

## 29. 模型配置

页面：`/docs/ide/Features/models`

### 功能点清单

- **models.json**：自定义模型列表 + 控制模型下拉列表显示；两级：用户级 `~/.codebuddy/models.json`、项目级 `<workspace>/.codebuddy/models.json`（项目级优先）

- **availableModels**：控制下拉列表显示哪些模型；未配置/空数组显示所有；可含内置+自定义 id
- **使用场景**：添加自定义模型；覆盖内置模型配置（改 url/apiKey）；限制可用模型列表（白名单）；项目特定配置（不同项目不同端点）

- **标签系统**：自定义模型自动标记 `custom` 标签，便于 UI 识别过滤
- **合并策略**：SmartMerge——相同 id 覆盖、不同 id 追加、项目级优先、availableModels 过滤最后执行
- **示例配置**：OpenRouter（openrouter.ai/api/v1/chat/completions）；DeepSeek（api.deepseek.com/v1/chat/completions）；本地 Ollama（localhost:11434/v1/chat/completions）
- **故障排查**：配置未生效（JSON 格式/路径/日志/环境变量）；模型未显示（availableModels 白名单/必填字段）；热重载未触发（防抖 1s/文件落盘/监听状态）

### UI 界面设计细节

- 模型下拉列表中展示模型；custom 标签标记自定义模型；配置保存后自动同步 UI 列表

## 31. 企业智能体

页面：`/docs/ide/Codebuddy-enterprise-edition/CloudAgent`

### 功能点清单

- **企业智能体**：云端 AI Agent 运行平台，完整 Agent 生命周期管理：
  - 创建和管理 Runtime（独立云端沙箱实例，含完整 Linux 文件系统和终端）
  - 实时对话（ACP 协议、SSE 协议，接收流式输出和工具调用结果）
  - 管理版本和快照（Checkpoint 和 Version，随时回滚）
  - 发布部署产物（Web 应用或静态资源发布公网）
- **核心概念**：
  - **Agent**：AI 助手的完整配置（模型、角色系统提示词、技能和工具）
  - **Runtime**：核心资源，独立 Agent 运行环境（云端沙箱 + Agent Manifest 声明式 JSON 配置 + 一个或多个 Session）；创建 Runtime 自动创建初始 Session
  - **Session**：用户与 Agent 的完整会话过程，独立对话历史和上下文
- **创建 Agent**：WorkBuddy 登录企业坐席账号 → 右上角"企业智能体"进入企业后台 → 填写配置 → 右上角"发布"
  - 基础配置：Agent 名称、模型（Auto 模式或内置模型）、System Prompt
  - 技能/专家/MCP 配置（自动同步到 Manifest）：技能包、专家绑定、MCP Server 配置
  - 高级配置：记忆（跨轮次保持上下文）、知识库（官方+自定义，RAG 检索）
- **Manifest**（声明式配置）：最小配置 `{"id","name","manifestVersion":"1.0"}`；配置项：基础（id/name/manifestVersion/system_prompt/system_prompt_file）、能力（rules/skills/plugins/mcp/subagents）、工作空间（name/repository/downloadUrl/ref/initShellCommand/initCommand）、环境（secrets 安全通道注入支持 ${VAR_NAME} 引用、envs）；自动注入 AGENTOS_RUNTIME_ID
- **Test Run**：左侧对话框切换 Test Run 模式测试 Agent 响应
- **渠道接入**：企微 AIBot、QQ 机器人、飞书、钉钉；每条接入记录对应一个 Bot→Session 绑定；企微 AIBot 使用 URL 回调连接（Token/EncodingAESKey 随机获取，绑定 Session，复制 Webhook 填入）
- **凭据管理**：Agent 调用 MCP/Skill/外部 API 时自动注入认证凭据（加密存储，运行时由代理层解密注入请求头，不明文暴露）
- **管理 Agent**：接入（复制链接分享，每人打开获得专属独立 Session；API 集成用企业 API Key）；版本管理（版本发布/历史）
- **Runtime 管理**（运维）：运行中（沙箱活跃服务）/ 休眠（空闲超时自动暂停，再次访问自动唤醒）/ 失败（创建或启动异常）；Session 与 Runtime 一一对应，无关联 Session 的 Runtime 建议清理
- **Session**：分享链接或 API 调用自动创建专属 Session；对话历史和文件存储独立；**超过 10 分钟无访问自动休眠**，再次访问自动唤醒；列表字段：调用方（用户=分享链接 / API Key=开放平台 API）；删除 Session 永久清除对话记录和文件
- **Agent 评测**：选择目标 Agent 和评测数据集，系统自动逐条运行测试用例按指定评分方式计算得分（消耗个人积分）

### UI 界面设计细节

- 企业后台"企业智能体"板块：Agent 列表（含 Session 数）、Runtime 状态列表（运行中/休眠/失败）、Session 列表（调用方标识）、凭据管理页（添加凭据表单）
- 新建 Agent 分步表单：基础配置 / 技能专家 MCP / 高级配置（记忆开关、知识库关联）
- 左侧对话框可切换 Test Run 模式
- 渠道接入：Bot 连接类型选择、Token/EncodingAESKey 随机获取按钮、Session 绑定选择、Webhook 地址复制

## 38. 微信 ClawBot 接入

页面：`/docs/ide/Platform-integration/weixinbot-guide`

### 功能点清单

- **功能**：将 CodeBuddy 接入微信（ClawBot 集成），绑定后可直接在微信中向电脑上的 CodeBuddy 发送任务并接收执行结果；**无需 App ID/App Secret 等开发凭证，扫码即可绑定**
- **前提条件**：电脑已安装并登录 CodeBuddy IDE；手机微信 >= 8.0.70
- **配置步骤**：
  1. 打开 CodeBuddy Agent 工作台 → 左侧 Claw 栏点击齿轮图标进入「Claw 设置」
  2. 集成列表中找到「微信 ClawBot 集成」→ 点击「配置」
  3. 等待二维码生成（按钮显示"绑定中..."）
  4. 手机微信扫描二维码（二维码有时效，过期重新配置）
  5. 扫码完成后卡片状态变「已连接」；换账号可「解绑」重新绑定
- **使用**：微信中直接对话（如"帮我总结今天桌面上最新的会议记录"、"帮我检查这个项目最近改过的接口有没有明显问题"、"帮我生成一个登录页原型"）；CodeBuddy 在电脑上自动执行并把过程和结果同步回微信
- **行为**：微信消息到达时 CodeBuddy 自动切换到 Claw 标签页并加载对应会话
- **FAQ**：绑定中卡住（确认运行/网络、重进设置、重启）；扫码无反应（确认微信账号、等待同步、重试）；微信发消息无响应（确认运行与 Claw 服务、检查状态、重新绑定）

- CodeBuddy Agent 工作台左侧有 **Claw 栏**（齿轮图标进设置）
- Claw 设置中集成列表卡片化，右侧"配置"按钮；配置中显示"绑定中..."状态；卡片状态「已连接」/「解绑」按钮

## 41. 支持·故障排查

页面：`/docs/ide/Support/Troubleshooting`

### 功能点清单

- **登录问题**：卡在登录界面 → 选择"在浏览器中打开"或"复制链接"自行打开浏览器完成验证
- **日志**：MAC 顶部帮助→打开日志文件夹（.zip 包）；Windows 手动路径 `C:\Users\<用户名>\AppData\Roaming\CodeBuddy\logs`
- **账户**：购买旗舰版后提示积分余额不足 → 检查是否购买/余额（企业后台查询）/登录正确账号（手机号重新登录）
- **远程开发（SSH）**：无法连接 → 测试本地 IDE 登录、远程服务器外网（ping）；设置 `codebuddy.remote.SSH.enableDynamicForwarding` 取消勾选重连；打开容器报错 → 卸载 VSCode 官方 RemoteSSH/dev-container 插件（IDE 已内置）
- **网络检查**（代理检测失败/警告）：
  - 代理问题（ECONNREFUSED）：检查 `http.proxy`、`codingcopilot.httpProxySettings`、`codingcopilot.httpProxyURL`；curl -x 验证；建议 HTTP 代理
  - Hosts 解析异常：检查 `/etc/hosts` 或 `C:\Windows\System32\drivers\etc\hosts`；nslookup/dig 对比；删错误映射刷新 DNS
  - 服务连通性失败：curl -v 验证；`timeout 30s curl -v`；按 timeout/certificate/proxy/connection refused 关键词排查
  - TCP 延迟失败：`nc -vz copilot.tencent.com 443`；检查出站规则放通 443
  - 丢包率异常：`ping -c 18`；区分 ICMP 受限与真实丢包
  - 错误码对应：3002/3003 链路连通性；3005 短时波动/请求超时（上下文约 200K）；10001 代理配置不当
- **Figma**：无法添加到对话 → 需申请编辑和开发权限（查看权限默认不开放 API）；开发侧可只开开发权限，先切普通模式再切开发模式
- **插件安装问题**：卸载插件 + 清空 cachedVSIXs（`~/Library/Application Support/CodeBuddy CN/CachedExtensionVSIXs`）+ 删除 `.codebuddycn/extensions/${插件id}` 重装；或安装 VSCode 1.100.0 对应版本插件
- **Python 无高亮/跳转**：卸载 Pylance，安装 BasedPyright（检查严格可在 `basedpyright.analysis.typeCheckingMode` 改 standard）
- **C/C++ 无法跳转/高亮**：安装 clangd（同时卸载微软 C/C++ 插件防冲突）；确认 compile_commands.json（`cmake -B build -DCMAKE_EXPORT_COMPILE_COMMANDS=ON`）
- **终端**：无法打开 → 设置搜索 Shell，开启 `Terminal › Integrated › Shell Integration: Decorations` 为 Enabled；终端无法复用 → zsh 慢速组件/主题问题，换 bash 或排查 ~/.zshrc
- **MCP**：需 Craft 模式使用（Ask 模式不能改文件禁用 MCP）；连接不上 → 删除配置文件名中的空格
- **语言**：约束 Agent 对话语言 → 配置 Rules
- **更新安全**：更新时提示"检测到应用安装目录下存在用户项目目录"（升级全量覆盖）→ 备份安装目录（Windows `C:\Users\{用户名}\AppData\Local\Programs\CodeBuddy`、macOS `/Applications/CodeBuddy.app`）中 bin/locales/resources/tools 外的个人文件 → 帮助→检查更新
- **Claw 工作空间**：历史会话找不到 → Claw 只展示最近任务，其他任务仅在工作空间列表；本地新建任务不建议用 Claw 作为工作空间

## 44. 核心流程总结：需求→设计→研发→部署

### 阶段一：产品需求（想法 → 需求）

- 打开 CodeBuddy IDE → 首页工作模式卡片"开始工作"（或右上角"打开 Agents"）进入智能体模式
- 选择工作模式（工作模式/编程模式）→ 输入自然语言需求（如"帮我在当前项目中添加一个用户登录功能"）
- AI 自动生成结构化需求文档（PRD）/ 需求优化建议；Plan 模式下 AI 提出澄清问题 → 生成需求总结 → 确认
- 支持粘贴截图、上传文件、`@` 引用文件/文档/Git/终端、导入 Figma 设计稿作为上下文

### 阶段二：产品设计（需求 → 设计稿）

- 自然语言生成交互原型 / 手绘草图转高保真设计稿 / 基于组件库（TDesign、MUI、Shadcn）快速拼装
- 通过内置 Figma 集成：Craft Agent 界面点 Figma 按钮 → 授权登录 → 选择设计文件 → Layers 面板选组件 → Add to Conversation 导入 IDE
- 通过"AI 视觉优化"用自然语言实时调整设计风格（预览页选组件 → 输入"请把这个按钮改成蓝色背景"）；或使用 DOM 编辑器直接改样式

### 阶段三：研发（设计稿 → 代码）

- 设计稿一键转代码（Figma2Code）：设计稿在对话框中 → 输入开发需求和技术栈偏好 → AI 生成前后端可维护代码 → Preview 面板查看还原效果 → 继续对话迭代
- 对话式编码：内联对话（⌘/Ctrl+I）或侧边栏对话；Ask（问答）/ Craft（Agent 执行）/ Plan（规划后执行）三模式切换
- 代码补全（含 NES 前瞻式编辑）持续提效；`@` 上下文引用、斜杠命令（/init /explain /fix /tests /cr /rules /summarize）加速
- 智能诊断、智能提交（AI COMMIT）、单元测试自动生成、检查点版本回溯、智能代码审查

### 阶段四：部署（代码 → 上线）

- 实时预览：Craft Agent 代码修改后自动打开 Preview；AI 视觉优化与 Send Errors 修复
- 一键部署：Cloud Studio（临时预览链接）、EdgeOne Pages（静态站生产）、CloudBase（前后端一体化）、Tencent Lighthouse（全栈/自定义服务）
- 部署后生成可公开访问链接便于团队验证反馈；修改代码重新触发部署自动更新；微信 ClawBot 远程收发任务与结果
