## 一、WorkBuddy 桌面端（复刻核心）

### 1. 产品与信息架构

**定位**：全场景 AI 办公工作台。「一句话下达任务 → 自主规划执行 → 交付可验收结果」。核心差异：能执行（不止对话）、自动操作本地文件、多步复杂任务、交付可验收结果。

**信息架构（三栏）**：
| 区域 | 功能 |
|---|---|
| **侧边栏** | 任务列表（按文件夹分组）+ 搜索 + 管理；底部用户头像 |
| **对话区** | 任务标题栏（4 个顶部操作）+ 消息列表 + 底部输入框 |
| **结果区** | 右侧面板：产物 / 全部文件 / 变更 / 预览 四视图 |

**侧边栏分组**：「任务」（最近访问/更新）与「空间」（按工作空间组织）。任务卡片 = 标题 + 当前状态 + 最近更新时间。

### 2. 新建任务栏（Task-Bar）——输入区 UI 规格

**输入框附近控件（从左到右 / 上下分布）**：
- **工作模式选择**（三档，官方中文名）：
  | 模式 | 行为 | 适用 |
  |---|---|---|
  | 问一问（Ask） | 仅问答与信息查看，不修改文件 | 了解内容、确认需求 |
  | 做一做（Craft） | 直接执行任务并修改文件 | 文档生成、表格处理、文件整理 |
  | 想一想（Plan） | 先生成执行计划，确认后再操作 | 多步骤任务、需审阅改动范围 |
- **切换模型**：内置模型清单 MiniMax（Excel/数据分析/PPT，快）、智谱 GLM（多步长流程）、Kimi（截图分析/图片转文档视觉类）、DeepSeek（日常问答/文案，快省）、腾讯混元（中文写作/会议纪要/中文文档）。对话界面模型选择器展示分组，支持快捷跳转配置页。
- **设置工作空间**：输入框左下角「选择工作空间」控件（文件选择器定位，无需手输）；未指定则新建任务时自动创建独立空间；建议按任务类型建空间（发票整理/周报/待处理照片）。
- **选择技能**：选择已安装技能，执行时自动调用；内置 20+ 技能包，兼容 OpenClaw 社区技能，支持自然语言创建自定义技能。
- **连接第三方应用**：快捷管理连接器。
- **权限管理**：默认权限（敏感操作需确认）vs 完全访问（减少确认、直接执行）。
- **新建任务**：每个对话独立任务，各自独立工作空间与上下文；支持多任务并行，执行中任务显示在左侧边栏可随时切换。

**上下文输入（4 种）**：①`@` 引用文件/文档/规则；②`Ctrl/Cmd+V` 粘贴剪贴板截图；③上传按钮或拖拽文件到输入框；④描述中补充目标/输入/输出格式/约束。

**发送**：点击发送按钮或回车；执行中输入框区域出现「停止」控件。

### 3. 任务管理（Task-Management）

- **任务状态（官方 6 态）**：进行中、已完成、失败、待处理、规划中、已归档。
- **搜索与筛选**：顶部搜索（按标题）；筛选面板按状态或日期；支持重置筛选。
- **任务级操作（右键/更多菜单）**：置顶、打开文件夹、重命名、保存到工作空间（可开启多 Agent 协作 + IDE 打开）、分享任务（生成公开链接）、删除、归档（归档后在「系统设置-数据管理」查看）。
- **工作空间级操作**：新建任务、打开文件夹、从列表移除。
- **继续处理**：已完成/失败/中断任务可重新进入补充消息，沿用上下文。

### 4. 任务对话（Conversation）

- **顶部操作（从左到右 4 个）**：①对话内搜索（关键词定位）；②分享任务（公开链接）；③历史提问（查看任务内历史对话、点击跳转）；④显示详情面板（打开右侧边栏）。
- **执行过程展示**：流式输出；阶段说明（"正在分析数据""正在生成报告"）；结果摘要；可展开/折叠的中间步骤。
- **支持文件类型**：PDF、Word、TXT、Markdown、RTF、Excel、CSV、TSV、PPT、图片（JPG/PNG/GIF/BMP）、ZIP/RAR、代码文件。
- **隐私授权边界**：文件处理默认本地完成、原始数据不上传云端；服务端仅处理片段、用后即弃；仅能访问主动勾选授权的文件夹；系统敏感目录自动拦截、高危操作二次确认。

### 5. 结果查看（Results）——右侧结果区 UI 规格

**四视图（Tab 切换）**：
| 视图 | UI 规格 |
|---|---|
| **产物** | 左产物列表 + 右预览区；Word/Markdown/PDF 文档、Excel/CSV 表格直接打开预览（不下载确认表头/数据/排版）；PPT、分析报告、交付文件 |
| **全部文件** | 左文件树 + 右文件内容 + 顶部已打开文件切换栏 |
| **变更** | 修改文件列表 + 每个文件改动情况 + 选中文件差异内容；代码/脚本/配置任务建议优先在此确认 |
| **预览** | 网页实时查看：当前页面地址 + 刷新入口 + 页面内容；确认结构/样式/交互 |

### 6. 权限管理（Permission-Modes）——安全沙箱 UI

- **切换位置**：新建任务输入框下方「默认权限」下拉菜单。
- **默认权限需确认的操作（4 类）**：写受保护/敏感路径（密钥、凭据、安全配置）；删除受保护文件/重要目录/批量删除；执行脚本/命令/外部程序；网络访问或敏感能力。
- **确认弹窗三要素**：操作内容、影响范围（是否在工作空间内/桌面/下载/源码）、执行理由。
- **完全访问**：关闭二次确认；切换时弹确认框需勾选风险确认；不建议用于生产资料/客户资料/财务/唯一副本、靠近桌面/下载/文档根目录、批量删除/重命名/覆盖、运行不了解的脚本。
- **沙箱额外保护**：命令优先在沙箱约束下执行；删除保护走安全删除/回收站；文件修改前自动备份（当前仅 Windows 支持）。

### 7. 系统设置（Setting）与记忆（Memory）

- **设置**（头像 → 设置 → 系统设置）：语言（中文简体/English）；字体大小可调；**显示模式**：简洁模式（简化对话界面、隐藏装饰性元素、折叠工具调用过程信息，默认开启）、非高风险自动安装（上传 Skill 仍显示安全检测，非高风险自动继续，高风险手动确认）、防休眠（便于手机远程操控与自动化持续）。
- **记忆**：从会话历史提取个人信息（事实、偏好习惯、人物关系、近期跟进事项），**每晚定期更新**，仅本人可见，对话时作为背景参考；可查看/编辑（对话式）/删除/导入（从其他 AI 同步）；记忆提取不消耗积分；删除后不再用于后续对话。
- **数据管理**：我分享的文件（复制链接/下载/取消分享）；已归档任务（删除需二次确认）。
- **帮助反馈**：描述 + 图片上传 + 「上传日志」勾选。

### 8. 模型（Model）

- **选择模式三档**：均衡（速度质量兼顾）/ 快速（响应优先）/ 极致（深度准确性优先）。
- **自定义模型**：设置页图形化管理（添加/编辑/删除），API Key 仅存本地 `workbuddy/models.json`；兼容 `~/.codebuddy/models.json`。
- **接入方式**：提供商接入（Token Plan/Coding Plan/自定义 API 一键）；本地部署（Ollama 11434，OpenAI 兼容，适合隐私/内网/零成本/离线）；自定义（URL/API Key/模型名，可跳过路径校验）。
- **添加模型弹窗流程**：选供应商 → 填 API Key → 选套餐支持模型（多步表单）；标准供应商能力标记（工具调用/图片输入/推理模式）自动写入。

### 10. 实践案例（交互规格）

- **批量重命名**：先展示「新旧文件名对照表」（表格）→ 用户确认 → 执行 → 反馈完成数量与跳过文件。
- **文档生成**：一句话生成 Word → 可继续对话二次修改；PPT 提供素材+页数+受众+风格。
- **数据分析**：Excel 拖入 → 描述指标/图表类型/维度/时间范围 → 图表+结论说明。
- **自媒体**：小红书（选题/标题/正文/话题/封面文案）；短视频脚本（钩子/口播/镜头/结尾）。

### 11. 移动端接入（助理生态）

- 平台：微信助理（推荐）、微信客服号、企微助理、QQ 机器人、飞书、钉钉机器人。
- 绑定流程通用：助理设置 → 目标平台「配置」→「绑定中...」→ 二维码/凭证 →「已绑定」（显示头像昵称）→ 解绑。
- 安全：每条远程指令多层来源校验；高风险任务（删除/系统配置修改/批准命令）需确认。

### 12. 商业化（积分体系）

- 积分=AI 任务资源消耗量；所有对话请求均消耗；扣减策略优先消耗最先到期。
- 三档个人版：标准 99/月（4000 积分）、高级 199/月（9000 积分）、旗舰 999/月（50000 积分）；体验版免费 500/月。
- 权益差异：自动任务数（3/15/30/99）、模型调度（体验版 Auto → 付费全模型）、创建项目数（5/10/15/20）、项目成员数（3/5/8/10）、个人助理数（3/5/8/10）。
- 企业版：企业旗舰版（SaaS）198 元/人/月；企业专享版（专有云）316 元/人/月（100 坐席起）。

## 二、WorkBuddy 移动端 App（15 页）

### 产品定位与执行模式
- 桌面端配套 App；多模态输入（文字/语音/图片/文件）；双模式执行：
  - ☁️ **云端工作**：云端沙箱执行，无需个人电脑（通勤/差旅）。
  - 🖥 **连接电脑**：远程操控桌面端 WorkBuddy，跨设备协作。
- 登录：QQ/微信/其他；**App 微信账号需与电脑端一致**才能连接电脑。
- 首次权限：相机、麦克风、存储/相册、通知。

### UI 页面规格
| 页面 | UI 规格 |
|---|---|
| **主页** | 顶部导航（≡ 打开侧边栏）→ 环境切换（云端/连接电脑）→ 欢迎区域（吉祥物+slogan）→ 快捷入口（横向滑动场景标签：幻灯片/视频生成/深度研究/文档处理…，「更多」查看）→ 底部输入栏（输入框 + 附件 + 语音 + 发送） |
| **侧边栏** | 顶部模式标签 → + 新建任务 → 自动化 → 专家 → 任务历史（进行中任务浅绿色底高亮）→ 底部用户信息卡（头像/昵称 + ⚙ 设置） |
| **发起任务 5 种** | 直接输入 / 快捷入口预填 / 侧边栏新建 / **系统分享入口**（其他 App 分享→WorkBuddy）/ 语音（按住录音、松开自动发送） |
| **选模型** | 输入栏常驻模型名（如「Auto ▾」）；模型选择面板 12 款，均带能力标签（推理/视觉）+ **积分倍率（x0.xx）** |
| **工具面板** | 输入栏左侧「+」展开 6 项：拍照（每次 1 张）/照片视频（最多 5 张）/手机文件/腾讯文档/定时任务/专家中心 |
| **任务执行** | 步骤卡片流：每步卡片 +「已完成」绿色标签 + 右侧「>」展开详情；运行中输入栏发送按钮切换为**停止按钮（■）**；长按 AI 回复 →「重新生成」 |
| **产物** | 对话内产物卡片（查看文件 + 右上角分享）；预览页右上角分享 → 导出 PDF/DOCX/Markdown/腾讯文档 |

## 三、CodeBuddy IDE（45 页，详见独立报告）

## 五、WorkBuddy 企业版

### 产品线
- **企业旗舰版（SaaS）**：198 元/人/月，1 坐席起，2000 积分/人/月，团队共享。
- **企业专享版（专有云）**：316 元/人/月，100 坐席起；VPC 物理隔离、私有链接、数据主权零泄露。
- **企业管理后台**：左侧导航含订单管理、发票管理（腾讯云控制台出票）。

### 企业级安全（三层纵深防御）
1. **技术防御层**：Bash 命令沙箱 / 文件系统隔离 / 防沙箱逃逸 / 默认只读 / allow-ask-deny 分层权限。
2. **管理管控层**：SSO 单点登录 / Credit 额度（按部门角色）/ IP 白名单 / 精细化工具调用权限。
3. **合规审计层**：Skill 安全审计 / skill-scanner 本地检查 / 数据本地执行不上传 / 服务端仅处理片段 / 400+ 认证（ISO27001/27018/27701、CSA STAR、等保 2.0）。

### 通信安全
- HTTPS 全链路 TLS1.2/1.3；IM WebSocket 通道（免开防火墙端口）；安全通信网关 Gateway Token。
